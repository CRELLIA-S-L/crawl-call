# Frames

`F-NNN` — boundaries this project will not cross whatever the evidence says.
A frame is not a hypothesis: no measurement can refute it, because refusing is the whole point.

Each frame keeps a table of what it has turned down and when.
A frame that has refused nothing in a long time is not proof of virtue — it usually means nobody is testing the boundary, or it was drawn where nothing was going to happen.

### F-010 — Abilities never shoot

```yaml
status: active
adopted: 2026-09-21
```

No ability the snake gains, and no upgrade of any kind, gives it ranged fire against bots. Destruction of geometry is the only exception, because it works on space, not on people.

**Rationale.** Concept §5: the moment the snake has firepower the asymmetry collapses "in the boring direction" — the player drives down the middle and mows. No playtest result reopens this; a player asking for a gun is asking for a different game.

### F-020 — Nothing recognisable is copied

```yaml
status: active
adopted: 2026-09-21
```

No layout, silhouette, landmark, character, interface element or name from an existing game is reproduced, and no franchise or map name appears in the store listing, devlog or pitch.

**Rationale.** Concept §2, §11: the test is "could a player with a hundred hours in the original name our map?" — if yes, out. Legal exposure is not a quantity a measurement can make acceptable.

### F-030 — The war stays comedy

```yaml
status: active
adopted: 2026-09-21
```

Violence is staged as physical comedy — swallowed whole, boots sticking out, tumbling soldiers — never as gore or military realism.

**Rationale.** Concept §2 "tone": a giant snake eating soldiers reads as body horror in realism and drags the game dark; the panicking lines only work as comedy. Also production and legal lines converge on the same choice.
